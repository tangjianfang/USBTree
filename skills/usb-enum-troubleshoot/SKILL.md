# USB 设备枚举失败排查

## 适用症状（触发条件）

- 插入 USB 设备后主机**毫无反应**（无提示音、lsusb/dmesg 无变化）；
- 设备出现但报告错误：Windows "无法识别的 USB 设备"/代码 10/28/43，Linux `device descriptor read/64, error -71/-110`；
- 设备时好时坏、换个口就好/换根线就好；
- 高速设备一直以全速运行。

## 排查前置

1. 明确角色：你是设备固件开发者，还是主机侧/用户？固件侧重点看阶段 B，主机侧重点看阶段 D；
2. 准备工具：万用表（VBUS 电压）、可换的**已知良好线缆**、抓包环境（Linux usbmon / Windows USBPcap，方法见 [协议分析仪与抓包](../../70-枝干-调试测试与安全/01-协议分析仪与抓包.md)）；
3. 打开完整背景手册：[枚举失败排查手册](../../70-枝干-调试测试与安全/02-枚举失败排查手册.md)。

## 排查流程（按阶段推进，每阶段先验证再进下一阶段）

### 阶段 A：供电与物理层（对应症状"毫无反应"）

| 步骤 | 动作 | 通过标准 |
|---|---|---|
| A1 | 万用表测设备端 VBUS | 4.75~5.25 V；低于 4.4 V 查线缆/端口供电能力 |
| A2 | 换已知良好线缆（排除仅充电线） | 主机出现插入事件 |
| A3 | 固件侧：确认 D+/D- 1.5kΩ 上拉已使能（固件初始化后） | 主机检测到接入 |

失败 → 典型根因：仅充电线、自锁电源欠压、上拉未使能。背景知识：[物理层与电气特性](../../10-树干-USB核心/03-物理层与电气特性.md)。

### 阶段 B：复位与速度协商

| 步骤 | 动作 | 通过标准 |
|---|---|---|
| B1 | 观察设备速度（lsusb -t / 设备管理器） | HS 设备应显示 480M；若恒为 12M 查 Chirp 握手 |
| B2 | 固件侧：确认复位中断到达、地址 0 上可响应 | 抓包可见主机发给地址 0 的令牌 |

背景：[信号编码与比特流](../../10-树干-USB核心/04-信号编码与比特流.md)（Chirp 时序）。

### 阶段 C：描述符读取（对应"无法识别的设备"/代码 43）

| 步骤 | 动作 | 通过标准 |
|---|---|---|
| C1 | 抓包过滤 `usb.transfer_type == 0x02`（中断）与 SETUP 包，找 GET_DESCRIPTOR(Device) | 设备返回 18 字节（或按 wLength 截断） |
| C2 | 核对设备描述符 `bMaxPacketSize0` 与固件端点 0 实际缓冲 | 一致 |
| C3 | 核对 `wTotalLength` = 配置+接口+端点+类描述符实际总长 | 抓包中主机一次读全长的长度与设备发送一致 |
| C4 | 核对 bLength/bNumEndpoints/bInterfaceClass 逐项 | 无字段矛盾 |

失败 → 典型根因：时钟偏差（内部 RC 振荡器）、SET_ADDRESS 生效时机错误、描述符长度自相矛盾。背景：[枚举流程与标准请求](../../10-树干-USB核心/08-枚举流程与标准请求.md)、[描述符详解](../../10-树干-USB核心/07-描述符详解.md)。

### 阶段 D：主机侧判定（Linux/Windows 错误码翻译）

| 现象 | 含义 | 动作 |
|---|---|---|
| Linux `error -110` | 超时：设备没应答 | 回阶段 B/C |
| Windows 代码 28 | 没有驱动：枚举其实成功 | 装驱动/检查接口类代码（[设备类索引](../../20-枝干-设备类协议/00-设备类索引.md)） |
| Windows 代码 43 | 设备报告故障/描述符被拒 | 回阶段 C；查类特定描述符 |
| Linux `error -71` | 协议错误（toggle/STALL 混乱） | 查 [错误处理](../../10-树干-USB核心/11-错误处理与可靠性.md) |

### 阶段 E：配置后的功能失败

SET_CONFIGURATION 成功但无功能 → 查接口类代码三元组与类驱动绑定、IAD 是否齐全（复合设备）、类请求是否正确响应（如 CDC 的 GET_LINE_CODING 必须可回读）。

## 验证收尾

修复后执行：插入 → `dmesg | tail`（Linux）或设备管理器（Windows）确认无错误码 → 跑一次完整抓包确认枚举序列干净（无重试/STALL 风暴）。

## 回退与升级

- 固件侧无法定位 → 用硬件分析仪抓电气层（[工具梯队](../../70-枝干-调试测试与安全/01-协议分析仪与抓包.md)）；
- 怀疑规范细节 → 按 [usb-spec-lookup](../usb-spec-lookup/SKILL.md) 技能查本地缓存的官方规范原文。
