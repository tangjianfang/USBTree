# 设备类索引

> 🌳 知识树位置: 枝干[设备类] → 分枝导航
> 上一级: [知识树总图](../00-知识树总图.md) · 基础: [描述符详解](../10-树干-USB核心/07-描述符详解.md)

设备类 (Device Class) 是 USB 知识树最大的枝干群：USB 核心只解决"怎么传"，设备类回答"传的是什么"。主机靠接口描述符的 `bInterfaceClass / bInterfaceSubClass / bInterfaceProtocol` 三元组绑定类驱动（详见[描述符详解](../10-树干-USB核心/07-描述符详解.md)）。

| 0x00 | 类在设备级声明 | — | 特殊布局设备 |
| 0x01 | Audio | [Audio-UAC/](Audio-UAC/00-UAC概述.md) | 声卡、麦克风、MIDI |

## 复合设备：一根树干上多根分枝

一台真实设备往往是复合设备 (Composite Device)——一个设备、多个接口、每个接口是一个设备类：

```
无线键鼠接收器 (composite)
├── 接口0: HID/键盘 (0x03)
├── 接口1: HID/鼠标 (0x03)
└── 接口2: 厂商自定义 0xFF (配置私有通道)
蓝牙适配器: 单接口 Wireless Controller (0xE0)
手机: MTP (0x06) + ADB (0xFF) + Audio (0x01) 复合
```

多接口功能的组合需要 **IAD** 描述符捆扎（[描述符详解](../10-树干-USB核心/07-描述符详解.md)），固件构造方法见[设备端固件栈](../60-枝干-主机侧与实现/03-设备端固件栈.md)。
